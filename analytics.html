// AMDAHL'S LAW: THE SPEEDUP LIMITATION OF SERIAL CODE FRACTIONS

Gene Amdahl (1967) established that the speedup of a program using N parallel cores is bounded by its non-parallelizable serial portion:

Speedup S(N) = 1 / ((1 − p) + (p / N))

Where p is the parallel fraction (0 to 1). As N → ∞, maximum speedup asymptotically approaches 1 / (1 − p). If only 15% of your code is serial, the theoretical maximum speedup is 6.67× — regardless of whether you have 16 cores, 64 cores, or 10,000 cores!

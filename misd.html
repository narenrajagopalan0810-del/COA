[03] MISD — MULTIPLE INSTRUCTION, SINGLE DATA

The most specialized quadrant in Flynn's Taxonomy. Multiple autonomous Processing Elements execute different instructions on a single shared stream of data. Primarily implemented as hardware systolic pipelines (e.g. Google TPU matrix engines) and Triple Modular Redundancy (TMR) fault-tolerant voting systems (e.g. NASA Space Shuttle, Boeing flight control).

STREAM PIPELINE & TMR VOTING
// DUAL OPERATIONAL MODES: SYSTOLIC PIPELINE VS FAULT-TOLERANT VOTING

Mode 1: Multi-Stage Systolic Stream Pipeline:
Data flows sequentially through a chain of specialized stages: Stage 0 (Offset) → Stage 1 (Gain ×2) → Stage 2 (Threshold > 10) → Stage 3 (Clamp ≤ 50). Each stage applies a unique instruction to the evolving data token.

Mode 2: Triple Modular Redundancy (TMR) with Hardware Majority Voter:
The same input token is fed into three independent execution units running different software algorithms. A hardware voting circuit computes a 2-out-of-3 majority vote. Try the INJECT BIT FLIP button to observe live fault masking!

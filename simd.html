[02] SIMD — SINGLE INSTRUCTION, MULTIPLE DATA

The core principle behind vector processors, modern GPUs, and CPU SIMD extensions (AVX-512, ARM Neon). A single Master Control Unit fetches and decodes an instruction once, then broadcasts it across multiple Processing Elements (PEs) to execute synchronously on distinct data elements.

DATA-PARALLEL VECTOR ARRAY
// SIMD EXECUTION & BRANCH DIVERGENCE PENALTY

Because all PEs share a single Program Counter, when code contains conditional branches (if/else), the architecture cannot branch in two directions at once. Instead, it must serialize both paths:

Phase 1: PEs where the condition is TRUE set MASK=1 and execute the if-branch while FALSE lanes are stalled.
Phase 2: PEs invert their mask; lanes where condition was FALSE execute the else-branch while TRUE lanes stall.

This is known as Thread Divergence in NVIDIA CUDA / GPU terminology. Observe the divergence meter below to track wasted cycles.

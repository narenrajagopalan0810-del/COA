[01] SISD — SINGLE INSTRUCTION, SINGLE DATA

The classic Von Neumann uniprocessor architecture (e.g., Intel 8086, early PDP systems). A single Control Unit fetches one instruction at a time from memory, decodes it, and directs a single Processing Element (ALU) to execute it on one data item. All computation occurs in strict serial order.

VON NEUMANN UNIPROCESSOR
// ARCHITECTURAL EXECUTION CYCLE: FETCH - DECODE - EXECUTE - WRITEBACK

In an SISD machine, parallel hardware units do not exist. For an array of size N, the machine executes the loop body N separate times.

1. Fetch: The Program Counter (PC) addresses instruction memory to load the next opcode.
2. Decode: The Control Unit (CU) identifies the instruction type and operand registers.
3. Execute: The single Processing Element performs the arithmetic or logic operation.
4. Write-back: The result updates the register file (R0-R3) or memory location.
